# Parallel work packages

Everyone starts from the same shared TailSignal ZIP and the `project-start` branch. Run `bash smoke/run_first_visit.sh /path/to/tailsignal_vet_dataset.zip` in your own course VM to generate baseline HDFS inputs and accepted Parquet tables. Start the NameNode and DataNode first and wait for HDFS safe mode to clear. The script prints the batch and output paths. See the [data contract](data_contract.md) for column types and [baseline evidence](baseline_evidence.md) for the run that already passed.

Each owner submits the listed files and VM evidence. Where a teammate’s finished output is needed for final integration, use the baseline or fixture in the meantime.
